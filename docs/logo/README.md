# Medusify logo

<img src="medusify-symbol.svg" alt="Medusify logo" width="96"> &nbsp; <img src="medusify-kachel-dunkel.svg" alt="Medusify app icon" width="96">

A rounded hexagon ring whose roof lifts off the base: a headless shop, built on Medusa. The roof is Medusify blue, the
base is ink. All files are generated by `build_logo.py`:

```bash
uv run --no-project --with shapely python build_logo.py
```

| File | Use |
|---|---|
| `medusify-symbol.svg` | The mark on light backgrounds |
| `medusify-symbol-auf-dunkel.svg` | The mark on dark backgrounds |
| `medusify-symbol-schwarz.svg`, `medusify-symbol-weiss.svg` | One colour (print, stamps, embossing) |
| `medusify-symbol-klein.svg` | Small cut for 16–32 px: thicker ring, wider gap |
| `medusify-kachel-dunkel.svg`, `medusify-kachel-hell.svg` | Rounded tile (manifest icon, README, social) |
| `medusify-app-ios.svg` | Full-bleed square for `apple-touch-icon` (iOS rounds it itself) |
| `medusify-app-maskable.svg` | Android maskable icon, mark inside the safe zone |
| `medusify-favicon.svg` | Browser tab: small cut on a dark tile, readable in light and dark tabs |

The app's PNG icons in `pwa/public/` are rendered from these SVGs (180 px apple-touch-icon, 192/512 px, 512 px maskable).

## Colours

| Role | Value |
|---|---|
| Ink (base on light) | `#18181B` |
| Blue (roof, graphics only) | `#3B82F6` |
| Dark tile | `#18181B` |
| Light tile | `#F4F4F5` |

Blue `#3B82F6` is for graphics. As text on white it misses WCAG AA; the app uses `#1D4ED8` (light) and `#60A5FA` (dark)
for text and buttons, measured in `docs/DESIGN.md`.

## Rules

- Minimum size 16 px; below 32 px use the small cut (`medusify-symbol-klein.svg`, `medusify-favicon.svg`).
- Clear space on every side: the height of the gap between roof and base, times two.
- Keep the gap. Without it the mark reads as a closed hexagon.
- Do not recolour the parts, add gradients, shadows or outlines, rotate, or stretch the mark.
- Medusa's own logo is never part of the Medusify mark. "Works with Medusa" uses Medusa's logo on its own, as Medusa's
  brand guidelines allow.
